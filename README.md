## 🔬 Core Architecture

Welcome to the **EDU-Pulse Research Lab**. This repository houses the frontend application built to deliver dynamic, high-performance user interfaces. Developed with an emphasis on aesthetics, fluid motion, and modularity.

### 🧪 Key Technologies

* **Framework:** React 19 + Vite (for ultra-fast HMR and building)
* **Styling:** Tailwind CSS (utility-first, deeply customizable)
* **Animation & Rendering:** Framer Motion (micro-interactions) & Three.js (3D visualizations)
* **Component Library:** Radix UI primitives & Lucide React for crisp iconography.

---

## 📊 Lab Components

### 1. `frontend/`
The primary application workspace containing the React ecosystem.
* **`src/components/`**: Modular, reusable UI components built on a custom design system.
* **`src/App.tsx`**: The main entry point routing the user experience.
* **`src/index.css` & `App.css`**: Global styles mapping our AI-themed aesthetic tokens.

### 2. Product Requirements
Detailed scope and objectives are outlined in our **Product Requirements Document (PRD)**, ensuring alignment with our goal of a seamless management interface.

## 🚀 Getting Started

To spin up the lab environment on your local machine:

```bash
# 1. Navigate to the frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Ignite the development server
npm run dev
```
